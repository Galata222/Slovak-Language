# **App Name**: Slovenský Spoločník

## Core Features:

- Interactive Dialogues: Play audio recordings of dialogues. Users can record themselves and get feedback.
- AI Conversational Partner: Use Gemini API to provide a chat partner for 'Talk about yourself' exercises. The tool provides targeted conversation based on the user's current unit.
- Vocabulary Mastery: Digital flashcards for vocabulary sections, including picture-based vocabulary.
- Grammar Engine: Interactive drills for grammar topics, providing exercises and explanations.
- Automated Writing Correction: Provide real-time grammatical feedback for writing tasks using generative AI as a tool to improve written Slovak.
- Skill Testing: Automated quizzes at the end of each unit to test the user's knowledge.
- Interactive Visuals: Digitalize the picture dictionary and Vysvetlivky with clickable elements.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to promote calmness and focus on learning.
- Background color: Very light blue (#F0F8FF) for a clean and unobtrusive learning environment.
- Accent color: Soft green (#90EE90) to indicate correct answers and provide positive reinforcement.
- Body and headline font: 'PT Sans', a humanist sans-serif that balances a modern look with approachability.
- Use clear, intuitive icons to represent different activities (reading, listening, writing, speaking, testing).
- Maintain the easy-to-follow structure of the original textbook with a sidebar for navigation and clear activity icons.
- Use subtle animations to provide feedback and enhance the interactive experience.
